## Percurso das cenas

- `arrival` — O leito junto à janela: `blood` → `reunion`, `staff` → `ordinary`, `leave` → `ordinary`
- `reunion` — Vinte e uma noites depois: `truth` → `limits`, `care` → `limits`, `feed` → `limits`
- `ordinary` — Uma recuperação compartilhada: `coffee` → `future`, `space` → `fim`
- `limits` — Não chame isso de destino: `explain` → `recovery`, `mara` → `recovery`, `control` → `dependency`
- `recovery` — Uma tarde que não gira em torno de você: `respect` → `future`, `demand` → `dependency`
- `dependency` — A conta da salvação: `release` → `recovery`, `refuse` → `fim`
- `future` — Quem escolhe voltar: `friend` → `fim`, `date` → `fim`
